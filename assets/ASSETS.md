# Design assets

These are original, editable SVG design references created for the Miqat V1 handoff.

- `home-screen.svg`: Home dashboard layout and visual hierarchy.
- `history-screen.svg`: Calendar and prayer-history layout.
- `settings-screen.svg`: Location, calculation, adjustment, and appearance settings.
- `design-system.svg`: Palette and typography reference.

The displayed dates and prayer times are placeholders for layout only. They must never be presented as verified real prayer timings in the finished application.
